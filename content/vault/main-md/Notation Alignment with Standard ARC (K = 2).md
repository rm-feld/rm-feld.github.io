> [!note] Notation drift (2026-07-09)
> $Y$ is now $\pm 1$-valued by default (defined directly via $2\cdot\mathbf{1}[\cdot > 0] - 1$ in the model-definition rows below). The old separate "signed response" $\tilde{Y} := 2Y - 1$ row has been removed — $\tilde{\cdot}$ is reserved for other objects (slice-decay terms, growth-rate exponents, correlation/variance components, etc.) and should not be reused for the response.
